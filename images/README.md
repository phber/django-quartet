# Images

Add these six files to this folder (`images/`) on the `claude/eloquent-mendel-bv54qf` branch — the filenames must match exactly, or update the `src` paths in `index.html` to match whatever you name them.

| Filename            | Used in                                   | Notes                                                                 |
|----------------------|--------------------------------------------|------------------------------------------------------------------------|
| `hero-band.jpg`       | Hero background (top of page)             | Full-band wide shot — the "main" photo. Landscape, generous headroom at top works best since the title overlays it. |
| `guitar-hands.jpg`    | About section, framed inset photo         | Close-up of the lead guitarist's hand on the fretboard.                |
| `venue-wide.jpg`      | Full-bleed strip between About and Repertoire | Wide room shot with the chandelier and staircase.                  |
| `media-bass.jpg`      | Media showcase, frame 1 ("Live…")         | Bassist, low angle.                                                     |
| `media-violin.jpg`    | Media showcase, frame 2 ("Minor Swing…")  | Violinist close-up.                                                     |
| `media-room.jpg`      | Media showcase, frame 3 ("Demobrickan…")  | Wide room/chandelier shot.                                              |

All photos are treated with a CSS sepia/duotone filter site-wide, so any reasonably sharp, well-lit source image will match the palette — no need to pre-color-grade them.

Photo credit (Mariscal Fotografia) is set in the footer already.
